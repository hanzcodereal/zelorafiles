How it works

  1. Choose or drag a file (up to 50 MB) and pick an expiration time.
  2. Click Upload File — watch real upload progress from 0% to 100%.
  3. Get a shareable link the moment processing finishes.
  4. The file deletes itself automatically once it expires. No manual delete, ever.

FAQ

Can I delete a file myself? No — by design, files can only disappear through expiration. This keeps shared links reliable for their intended lifetime.

What happens after expiry? The link returns a 410 Expired page and the file is permanently removed.

Is there a size limit? Yes, 50 MB per file.
